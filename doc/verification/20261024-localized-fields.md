# 2026-10-24 国际化字段与租户名称交付验证

单体 `single.simplepoint.online:8000` 和微服务 `home.simplepoint.online:8000` 已完成更新。租户资源名称已接入公共多语言编辑器，保留平台翻译与租户覆盖的边界。此前确认的“资源管理”“工作空间”改名已通过负责人接口补为中文覆盖值，并验证实际菜单显示。

## 已验证

- `@LocalizedField`、`LocalizedText`、schema 自动编辑器及领域内 JSON 持久化；包含 Unicode 字符长度、规范语言标识、语言数量与重复语言校验。
- 中文、英文、日文译文保存与读取；抽屉取消恢复、完成仅保留草稿、主表单一次保存；语言切换更新列表而不改变资源身份。
- 添加语言读取 `common,menu` 中的继承翻译；恢复继承显示平台文本；取消不修改已保存的默认名称及覆盖值。
- 只读字段直接调用不能修改；隐藏/脱敏字段序列化不泄露译文；跨空间读取、普通成员写入被拒绝；旧客户端更新其他字段不清空译文。
- 平台检查更新及显式定义覆盖保留租户译文；平台消息与资源定义不被租户改名修改。
- 数据库一致性备份、独立副本 V18 迁移、重复迁移及校验、正式迁移校验均完成。迁移只新增可空列，不猜测或批量填充历史编辑语言。
- 完整发行包包含前端；10 个服务镜像按完整文件清单校验，服务健康；两个入口均验证六个联邦模块的清单、入口、声明资源，以及各 350 个宿主 JS/CSS 文件。

根 `./gradlew test -Psimplepoint.frontend.skip=true` 成功，本次参与任务的报告合计 5094 项、0 失败、0 错误、142 跳过；跳过项沿用原有环境条件，不宣称已执行相应外部引擎场景。前端 15 项专项测试、全模块类型检查、国际化检查及严格 UI 规范检查通过。发行构建未跳过前端。
