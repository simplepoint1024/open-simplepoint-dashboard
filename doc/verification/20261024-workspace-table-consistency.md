# 工作空间与表格一致性验收

实施及验证日期：2026-10-24。范围：工作空间切换与设置、租户资源管理、我的套餐、资源注册范围、共享表格高度与分页。单体和微服务复用同一实现。

## 改动

- 不支持平台空间的应用工作台、表单数据底座、流程事项/待办声明为租户功能；首页卡片与快捷入口也按授权页面显示。AI 的平台能力及平台可用的消息等功能保留。未实现的应用模板、市场占位菜单停用。
- 空间设置与个人资料共用 `SettingsLayout`，采用侧边设置目录，保留基本资料、标识与外观、负责人信息。保存复用 SForm 与操作锁，读请求跟随页面及授权范围；未保存的内容保留并阻止误关闭。
- 租户资源管理和我的套餐分别进入独立标准列表，复用 SimpleTable、ResourceDrawer、TableActions 和服务端 schema/权限；兼容旧组件标识及书签，后台保留页不能重定向当前页。
- 工作空间选择改为单层搜索列表，复用 EntitySelect 的授权目录、分页、请求取消、搜索和已选项查询；提供类型图标、选中状态与键盘操作。空间记忆与切换授权逻辑保留。
- SimpleTable/DataTable 的空表和有数据表格均占满所属有界区域，滚动留在数据区；分页位于滚动区之外。显式高度的嵌入表格保留其高度预算；全屏时填满视口。旧版与当前 Ant Design 加载容器均有对应高度链。
- 普通表格分页统一为 50/100/200/500，默认 50。共享默认、列表控制器、服务端 schema、JPA/领域查询及表单记录查询上限一起调整；目录检索和传输协议仍保留独立的限制。卡片仍按可用宽度和卡片行数计算容量，切回列表恢复列表分页。
- 套餐的名称、历史权益来源和状态由公共展示规则处理，租户与平台管理端一致；历史权益不再显示成无名称记录，不删除历史权益或伪造激活时间。
- 新规则已补充到根 `AGENTS.md`，包括页面职责、资源范围、首页入口、分页及滚动约束。
