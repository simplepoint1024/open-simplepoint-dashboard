# 角色资源配置：整目录授权与自适应布局

角色资源配置支持对当前资源及其所有可见、可授权下级一次性授权或撤销，包含未展开、未翻页的菜单、页面和操作/API 资源。操作前由后端计算影响数量并在界面确认；提交时在角色锁下重新计算并比对预览版本，资源或授权变化则整体拒绝。批量操作立即保存，与待保存的单项修改互斥；旧授权仍承载数据或字段策略时，撤销会被拦截。单次批量操作最多覆盖 5000 项可见资源，超出时需选更小的下级目录。

左侧导航目录只显示可导航资源，操作/API 资源保留在右侧授权区。抽屉左右面板等高并各自滚动。右侧资源授权、数据权限和字段权限按可用宽度横排、自动换行，同一行以最高内容等高对齐；数据和字段入口仍为预留，不改变权限。

验证：`RoleResourceConfigurationHttpTest` 14 项、`pnpm typecheck`、`node scripts/sync-i18n-bundles.mjs`、`pnpm build:common`、隔离 API 数据的生产前端浏览器工作流均通过。数据库无迁移。本地 Common 已更新为 `simplepoint203/common:20260922-resource-bulk3`，部署后健康检查及 HTTPS 页面回归通过；其他服务未替换。回滚镜像与脚本见 `.simplepoint/deploy203/release-20260922-resource-bulk3/`。
