# Agent 与 Workflow 工作台生产化计划

## 1. 目标与验收原则

本计划承接 Skill Workflow Visual Designer 的质量基线，按独立的纵向功能闭环实施。每一项必须同时完成前端、后端契约、国际化、错误处理、可访问性与自动化验证；当前项未通过验证前，不进入下一项。

统一验收标准：

- 功能可用：正常路径、空数据、校验失败、并发或重复操作、权限不足及服务异常均有确定行为。
- 易用一致：页面布局、状态表达、反馈、表单保留、危险操作确认与平台基础组件保持一致。
- 可扩展：定义、版本、依赖和执行使用稳定契约，不通过页面硬编码限制后续能力扩展。
- 可观测：关键操作具有审计、指标、结构化错误和可定位的执行事件。
- 可验证：单元测试、模块检查、前端类型检查和真实本地服务 E2E 均通过。

## 2. Agent 生产化闭环

- [x] A1. 注册表与工作区信息架构：主从选择、后端分页、空状态、状态国际化、键盘可操作。
- [x] A2. 不可变版本向导：分步配置、结构化 Schema 编辑、模型与 Skill 依赖校验、草稿防丢失、发布/废弃确认。
- [x] A3. 执行中心：结构化输入、审批/暂停/恢复/取消/人工介入确认、轮询容错、链路与事件可读化。
- [x] A4. 后端成熟度：权限与作用域、幂等与并发、审计、限额、结构化错误、指标与安全边界测试。
- [x] A5. Agent 验收：前后端检查、真实创建—版本—发布—执行—观测闭环、文档和本地服务验证。

## 3. Workflow 生产化闭环

- [x] W1. 工作流注册表与设计工作区：信息架构、分页、空状态、国际化和可访问性。
- [x] W2. 可视化编排器：节点面板、画布、属性面板、连线/分支/并行/循环约束、撤销重做和自动保存。
- [x] W3. 版本与发布：结构化输入输出、静态校验、依赖固定、变更摘要、发布/废弃与防误操作。
- [x] W4. 执行与调试：持久化节点检查点、协作式暂停恢复、人工审批、自动重试补偿、事件时间线和失败定位。
- [x] W5. 后端成熟度：持久状态机、幂等并发、租户隔离、权限审计、预算限额、指标告警和安全测试。
- [x] W6. Workflow 验收：前后端检查、真实设计—校验—发布—执行—恢复闭环、文档和本地服务验证。

## 4. 最终交付门槛

- [x] Skill、Agent、Workflow 全部模块测试和前端构建通过。
- [x] 数据库按项目标准流程干净初始化并完成初始化后冒烟测试。
- [x] 本地服务重新构建、启动并通过健康检查与核心页面/API 冒烟测试。
- [x] 清理验收数据和本轮临时运行资源，不删除不可恢复的用户数据或外部资源。
- [x] 记录无法由本地环境完成的真实外部系统门槛及所需凭据，不以模拟结果冒充真实验收。
