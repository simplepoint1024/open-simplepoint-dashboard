# 租户资源目录与空间设置

## 边界与存储

组织租户默认使用平台资源（`resource_mode=PLATFORM`）。只有租户所有者或租户管理员在当前组织工作空间切换到 `CUSTOM`，才启用独立目录。个人空间和平台工作台不能切换。首次切换在同一事务内同步当前平台授权；同步失败时仍保持平台模式。

平台资源表的 `code` 与 `path` 全局唯一，且平台会自动发现、更新这些记录，不能在该表混入租户自建项。`simpoint_saas_tenant_resources` 使用 `(tenant_id, id)` 复合主键；平台来源项的 `id` 和 `platform_resource_id` **都等于原平台资源 ID**，编码也保留原编码。租户自建项使用独立 UUID 与 `tenant.<tenantId>.<uuid>` 编码。接口返回 `origin=PLATFORM|TENANT` 标记来源。

租户可以调整平台来源项的名称、图标、排序、所在目录和本地启停状态；来源项的编码、类型、组件及可授权性始终由平台控制。租户自建目录和模块只负责组织导航。租户自建页面必须绑定本租户已授权的平台页面，并沿用其组件；租户不能自建 API、操作或数据/字段权限，也不能通过自建资源扩大平台许可。自建页面可以作为角色授权对象，但对应的平台页面必须仍获授权。

## 生效规则

平台模式沿用原来的路由、角色授权与权限计算。自定义模式下，角色资源配置按租户目录查询和保存，菜单也按该目录生成。已有平台角色授权保留；只有当前目录中仍生效的来源项能产生平台权限。权限计算和授权写入时再次检查**当前平台套餐授权**，所以平台撤销授权后，无须等待租户手动更新即可阻断旧目录中的权限。公开资源仍按平台公开策略生效。切回平台模式不删除租户目录和角色授权，但它们暂不参与菜单与权限计算。模式、目录、同步变更都会增加租户授权版本，使已有权限快照失效。

平台模式的角色授权树通过资源祖先关系补全不可授权的目录、模块：只要存在当前空间可用且属于当前租户套餐或公开的下级资源，即可展示其仍启用、未删除且适用于当前空间的结构祖先。目录本身不必加入应用套餐。列表、分页计数和子节点标记使用同一 SQL 过滤规则；补全仅限 `grantable=false` 的 `GROUP/MODULE`，不会扩大页面和操作的许可范围。整目录授权仍逐项检查可授权性与套餐边界，套餐撤销后对应的空目录也会隐藏。

资源授权预览默认按资源树展示本次变更，保留目录和页面上下文，分别标记新增授权、取消授权、权限调整；可切换查看保存后的全部授权。取消项不会因不再属于最终授权集而消失；规则变更显示国际化名称的前后对照。预览只分页读取现有授权，并通过 `POST /role-resource-configuration/roles/{roleId}/resource-context` 批量补齐缺失祖先（每次至多 200 个起点、合计至多 5000 项），沿用平台或租户自定义目录与可见性检查。前端使用虚拟树，搜索保留上级上下文；确认只提交预览时的明确变更与原始版本。

页面自身的授权（例如 `.view`）与下级操作分开：页面名称旁和资源树中页面行的复选框只控制该页面。目录的复选框仍联动所有下级，页面配置里的“全部”用于一次选择当前页面及所有下级。只读角色可以只获得页面访问权限，不会顺带获得新增、修改、删除等操作；查询接口仍检查相应 `.view`，写接口检查各自操作权限。

“更新平台授权资源”先预览变化，再按来源 ID 自动映射新增项，更新平台安全字段，停用已撤销来源项及指向它们的租户页面别名；本地展示调整和手动停用保留。“覆盖平台来源资源”执行相同安全检查，并将平台来源项的展示字段和手动停用状态恢复为平台值。两种同步都保留租户自建项和角色授权记录。预览仅供确认；提交时在事务中重新计算，以当前授权为准。同步本身不会自动把新资源授予普通角色，租户所有者可在角色资源配置中分配。

## 接口与迁移

空间设置与租户资源管理分别注册为 `workspace.settings.view`、`workspace.resources.view` 页面资源，位于工作空间目录。前者面向组织与个人租户，后者仅面向组织租户；两者都会通过现有资源同步进入核心应用及相应默认套餐。管理接口仍要求当前组织租户所有者或管理员身份，页面授权不能单独提升管理权限。

空间设置通过 `/tenants/current-profile` 维护名称、简介与品牌信息；`/tenants/current-resources/mode` 切换模式。`/tenants/current-resources` 提供分页目录、创建、编辑、删除自建项；`/sync/preview` 和 `/sync` 提供预览、更新与覆盖。所有租户 ID 由当前授权上下文取得，不接受请求体指定其他租户。

上线前执行 [`20260922-tenant-resource-catalog.sql`](../deployment/sql/20260922-tenant-resource-catalog.sql)。该脚本为旧租户设置平台模式默认值并创建独立目录表与索引。上线后默认行为不变；只有租户主动启用时才生成目录数据。
